# Creative thinking

Use external randomness to develop an original, useful direction within the user's brief. Focus exploration on choices the user has left open.

## Get a seed

Use a seed supplied for this task. Otherwise, run [scripts/generate_seed.py](scripts/generate_seed.py) with Python 3 using its absolute path. The helper samples seven distinct words from the bundled vocabulary offline. Use its output directly, including unfamiliar words; let the helper read the vocabulary file. If execution is unavailable, state that limitation and work from the user's brief.

## Abstract a direction

Look beyond individual meanings to sounds, fragments, rhythms, contrasts, shapes, and relationships across the seed. Translate useful connections into task-relevant principles governing structure, behavior, pacing, or experience. Unfamiliar words can contribute through their form alone; use whichever connections serve the task.

The result of this step is a short working brief that stands on its own in the user's domain: the organizing principle, the substantive choices it changes, and how those choices serve the user's purpose while preserving their constraints. Include only that task-level direction in the execution brief; keep the seed and association notes outside it.

Work from that brief. For a request to explore alternatives, give each direction a distinct organizing principle with concrete consequences for the result.

If the result still mainly depicts or names seed words after revising the brief, consider a fresh execution context containing only the task, constraints, and abstract brief.

## Develop and assess

Deliver the requested concepts or finished work, using the relevant domain guidance for implementation and validation. Remove details that distract from the direction's purpose. Explain the seed's influence when the user requests it; otherwise, present the work on its own merits.
