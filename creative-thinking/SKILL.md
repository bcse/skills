# Creative thinking

Use external randomness to develop an original, useful direction within the user's brief. Focus exploration on choices the user has left open.

## Get a seed

Use a seed supplied for this task. Otherwise, run [scripts/generate_seed.py](scripts/generate_seed.py) with Python 3 using its absolute path. The helper samples seven distinct words from the bundled vocabulary offline. Use its output directly, including unfamiliar words; let the helper read the vocabulary file. If execution is unavailable, state that limitation and work from the user's brief.

## Create from the seed

Treat the seed as a secret code: try to decrypt it and draw inspiration from it. Look beyond the surface for subpatterns.

Let the seed shape the work through associations and subpatterns such as sounds, fragments, rhythms, or relationships. Follow useful connections while preserving the user's purpose and constraints.

## Deliver the work

Deliver the requested concepts or finished work, using the relevant domain guidance for implementation and validation. For alternatives, develop meaningfully different directions. Explain the seed's influence when the user requests it; otherwise, present the work on its own merits.
